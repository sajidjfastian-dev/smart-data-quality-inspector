After data is uploaded, the Overview section should contain charts only and provide a complete overview of quality issues related to the configured quality controls.

**Why:** The user explicitly requested “charts only” and a “360 degree overview” based on defined controls, with dashboard images supplied as visual references.

**How to apply:** Keep detailed tables and recommendations outside Overview. Derive charts from real inspection findings, including custom rules; distinguish unassessed controls from zero findings. Do not invent historical trends to imitate reference charts.
